# Recovery of original A1 and A3 executable evidence

The missing bodies were recovered from the user's PowerShell PSReadLine command-history file. `evidence/recovered_original_tests/PROVENANCE.json` records the whole-history SHA-256, exact line ranges, raw excerpt and normalized Python hashes. Only selected research here-strings are included; unrelated history is excluded. Normalization removes the history serializer's trailing multiline backtick and extracts the Python here-string. This recovers original code text; it is not newly designed replacement logic.

Two original A1 attempts were found. The first shell invocation is truncated and its schema includes retention_hours. It is preserved as attempted text, not asserted as a successful original execution. The second body has the same six-field schema as the saved A1_result.json. A new isolated rerun produces identical parsed JSON, including safe=true and zero flagged files. A1 is a synthetic checker timestamp counterexample, without physical Parquet data or an engine VACUUM; it is not an engine-valid causal experiment.

The original A3 body is a read-only archived-outcome inspection, not a standalone Delta table experiment. Its new execution reads all 3,200 original outcome views and reports 2,696 comparable error-free runs, 504 error runs, and zero plan/execution differences among error-free records. A separate NEW analysis (`reproduction/a3_archived_outcome_audit.py`) recomputes the set difference from plan and non-log deleted paths: all recorded differences match; 367 of 504 error-stratum runs differ. Neither analysis executes VACUUM or creates original observations. A3's formerly empty evidence directory was not modified.

No original command timestamps or captured historical stdout were recovered. Today's execution logs are labelled new reruns; history text plus the saved A1 result does not establish an original exit status. Recovered code has no invented version identifier or historical execution date.
