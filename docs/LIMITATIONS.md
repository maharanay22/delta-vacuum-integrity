# Scientific and artifact limitations

- Original 168-hour matrix F1 exposure is zero; later F1/168 validation is supplemental.
- F3 raw repeated-tombstone conditions are broader than class-specific exposure because active data paths retain independent protection.
- F4 LITE latent conditions are distinct from the FULL orphan-cleanup mechanism.
- Failure classes can overlap. F4 missing-file read evidence is not isolated causality in every affected run; stored original errors can be truncated.
- 2,075 exact absolute run clocks and most complete aged pre-VACUUM per-run copies were not archived. Relative exposure is reconstructible from saved original logs, mtimes and offsets, with 1,125 retained run directories cross-checked.
- A1 lacks a complete retained driver; A2 has multiple evidence levels; standalone A3 is absent.
- Two legacy checker fixtures are excluded pending redistribution provenance. Their tests are explicitly skipped, not counted as passing.
- No clean-machine full-engine run, byte-identical wheel rebuild, general distributed/concurrency safety proof, or universal Delta Lake correctness claim is made.
- License scope/owner approval, author citation verification and the remaining blockers must be resolved before publication. No DOI or published release version has been assigned here.
